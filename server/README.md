# 📡 سرویس همگام‌سازی مرغینو

این سرویس باعث می‌شود هرچه کارگر در گوشی خودش ثبت می‌کند، خودکار روی گوشی مدیر هم دیده شود.

بدون این سرویس، مرغینو کامل کار می‌کند ولی اطلاعات هر گوشی جداست.

---

## راه‌اندازی روی لیارا (قدم به قدم)

### ۱) حساب بسازید
در [liara.ir](https://liara.ir) ثبت‌نام کنید و کیف پولتان را کمی شارژ کنید.
یک اپلیکیشن کوچک برای این کار در ماه هزینه‌ی زیادی ندارد.

### ۲) ابزار لیارا را نصب کنید
روی کامپیوتر خودتان (نیاز به Node.js دارد):

```bash
npm install -g @liara/cli
liara login
```

### ۳) اپلیکیشن بسازید
در پنل لیارا → **اپلیکیشن جدید**:

- پلتفرم: **Node.js**
- نام: مثلاً `morghino`
- پلن: کوچک‌ترین پلن کافی است

### ۴) دیسک بسازید (مهم)
در پنل همان اپلیکیشن → بخش **دیسک‌ها** → دیسک جدید با نام **`data`** و حجم ۱ گیگابایت.

> بدون دیسک، با هر بار ری‌استارت شدن اپلیکیشن، اطلاعات مرغداری پاک می‌شود.
> فایل `liara.json` در ریشه‌ی پروژه، این دیسک را به مسیر `/app/server/data` وصل می‌کند.

### ۵) بالا ببرید
در پوشه‌ی پروژه (همان‌جا که `liara.json` هست):

```bash
liara deploy --app morghino
```

بعد از چند دقیقه آدرسی مثل `https://morghino.liara.run` می‌گیرید.

### ۶) درستی کار را بررسی کنید
آدرس زیر را در مرورگر باز کنید:

```
https://morghino.liara.run/api/health
```

اگر چیزی شبیه `{"ok":true,...}` دیدید، سرویس بالا است.

## اتصال گوشی‌ها

### روی گوشی مدیر
۱. منو ← **همگام‌سازی با سرور**
۲. آدرس سرور را بنویسید: `https://morghino.liara.run`
۳. **ساخت مرغداری تازه روی سرور** را بزنید
۴. یک **کد مرغداری** مثل `MRG-A7K2-9FXQ` می‌گیرید — این کد را نگه دارید

کد با رمزهای فعلی مدیر و کارگرِ همین گوشی ساخته می‌شود. پس قبل از این کار،
از منو ← تنظیمات، رمزها را همان‌طور که می‌خواهید تنظیم کنید.

### روی گوشی کارگر
۱. منو ← **همگام‌سازی با سرور**
۲. همان آدرس سرور و **کد مرغداری** را وارد کند
۳. **رمز کارگر** را بزند و «اتصال» را لمس کند

از این به بعد خودکار است. مدیر می‌تواند با دکمه‌ی «📨 فرستادن کد برای کارگر»
آدرس و کد را در واتساپ یا تلگرام برای کارگر بفرستد.

## چطور کار می‌کند

- هر رکورد یک **زمان آخرین تغییر** دارد و هنگام ادغام، تازه‌ترین نسخه برنده است.
- تلفات و دان روزانه **شناسه‌ی تاریخ‌محور** دارند، پس اگر کارگر و مدیر هر دو برای
  یک روز ثبت کنند، رکورد تکراری ساخته نمی‌شود.
- حذف، پاک کردن واقعی نیست؛ رکورد نشان‌دار می‌شود تا از گوشی دیگر دوباره زنده نشود.
- اگر اینترنت نباشد، ثبت‌ها روی گوشی می‌مانند و به‌محض وصل شدن خودشان بالا می‌روند.
- هر دستگاه حدود هر یک دقیقه، و همچنین هنگام باز کردن برنامه و بعد از هر ثبت،
  همگام می‌شود.

## داده‌ها کجا ذخیره می‌شوند

در پوشه‌ی `server/data/` به شکل یک فایل JSON برای هر مرغداری. حجمشان ناچیز است
(یک دوره‌ی کامل چند ده کیلوبایت). نوشتن اتمیک است: اگر وسط ذخیره برق برود،
فایل قبلی سالم می‌ماند.

برای پشتیبان‌گیری کافی است همان پوشه را کپی کنید. در خود برنامه هم
منو ← پشتیبان‌گیری، فایل پشتیبان می‌دهد.

## نکته‌ی امنیتی

هر کسی که **کد مرغداری** و یک **رمز ۴ رقمی** درست را داشته باشد می‌تواند داده را
بخواند و بنویسد. کد مرغداری تصادفی و طولانی است و حدس زدنش سخت؛ ضمناً بعد از
۱۰ بار رمز اشتباه، آن دستگاه برای ۱۰ دقیقه قفل می‌شود.

این سطح برای یک مرغداری کافی است، ولی جای احراز هویت واقعی را نمی‌گیرد.
**کد مرغداری را عمومی نکنید.**

## اجرای محلی برای آزمایش

```bash
node server/server.js
# روی http://localhost:3000 بالا می‌آید
```
