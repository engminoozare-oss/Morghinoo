# 🐔 مرغینو — برنامه‌ی مدیریت مرغداری

برنامه‌ی تحت وبِ نصب‌شدنی (PWA) برای مدیریت یک دوره‌ی پرورش مرغ گوشتی (حدود سه ماه).
روی **اندروید، آی‌اواس و ویندوز** نصب می‌شود، **بدون اینترنت** کار می‌کند و همه‌ی اطلاعات
روی خود دستگاه ذخیره می‌شود.

طراحی ظاهری و کاربردی برای کارگر مرغداری ساده نگه داشته شده است: دکمه‌های بزرگ، آیکن به‌جای متن،
تاریخ شمسی و اعداد فارسی.

---

## دسترسی‌ها

| نقش | رمز پیش‌فرض | دسترسی |
|---|---|---|
| 👨‍💼 مدیر | `1234` | هر سه تب + تنظیمات، تعریف دوره، واکسن، هزینه و فروش |
| 👷 کارگر | `1111` | تب گزارش وضعیت (ثبت روزانه) + دیدن جمع‌بندی |

تب «هزینه و درآمد» برای کارگر قفل است. رمزها را مدیر از منو ← تنظیمات عوض می‌کند.

---

## سه تب برنامه

### ۱) 💰 هزینه و درآمد — فقط مدیر
- ثبت هزینه در ۱۲ دسته: خرید جوجه، پیش‌دانه، ذرت، سویا، کنسانتره، نمک، کاغذ بستر، واکسن، تعمیرات، قبوض، کارگر، متفرقه
- برای هر هزینه: **مقدار، فی، مبلغ کل و تاریخ خرید** (مبلغ کل خودکار حساب می‌شود؛ اگر مبلغ کل را بنویسید، فی خودکار درمی‌آید)
- **فروش:** فی روز مرغ × وزن کل مرغ‌ها (میانگین وزن × تعداد باقی‌مانده) = مبلغ کل فروش
- **سود خالص دوره = مبلغ کل فروش − مبلغ کل هزینه‌ها** + هزینه‌ی هر جوجه و قیمت تمام‌شده‌ی هر کیلو

### ۲) 📋 گزارش وضعیت — مدیر و کارگر
- اطلاعات ابتدای دوره: تاریخ ورود جوجه، نژاد و شرکت جوجه، وزن اولیه، تعداد گله
- **ثبت روزانه‌ی تلفات** و **ثبت روزانه‌ی وزن دان مصرفی** با دو دکمه‌ی بزرگ
- **وزن‌کشی هفتگی** با جدول روند رشد و نرخ تبدیل هر هفته
- **برنامه‌ی واکسن**: تاریخ را مدیر تعیین می‌کند، **یک روز قبل** به مدیر و کارگر یادآوری می‌شود
- **نرخ تبدیل** در هر لحظه و برای هر تاریخ دلخواه

### ۳) 📝 جمع‌بندی
- خلاصه‌ی عددی دوره + نکات نژاد، واکسن، دان، کارگر و نتیجه‌گیری کلی + امتیاز دوره
- خروجی چاپ/PDF و اشتراک‌گذاری متن گزارش

## 🧮 فرمول نرخ تبدیل

```
تعداد جوجه‌ی زنده = تعداد کل گله − کل تلفات تا تاریخ استعلام
دان مصرفی هر مرغ  = کل دان مصرفی از ابتدای دوره تا تاریخ استعلام ÷ تعداد جوجه‌ی زنده
نرخ تبدیل         = دان مصرفی هر مرغ ÷ میانگین وزن ثبت‌شده (کیلوگرم)
```

اگر هنوز وزن‌کشی ثبت نشده باشد، وزن اولیه‌ی جوجه استفاده می‌شود و برنامه این موضوع را هشدار می‌دهد.

## 🔔 یادآورها

| یادآور | زمان | برای |
|---|---|---|
| ثبت تلفات روز | هر روز (ساعت قابل تنظیم، پیش‌فرض ۱۷) | مدیر و کارگر |
| ثبت دان مصرفی روز | هر روز | مدیر و کارگر |
| وزن‌کشی | هر ۷ روز پس از آخرین وزن‌کشی | مدیر و کارگر |
| واکسن | یک روز قبل و روز واکسن | مدیر و کارگر |

یادآورها همیشه به‌شکل کارت رنگی بالای تب «گزارش وضعیت» دیده می‌شوند و اگر اجازه‌ی اعلان داده شده باشد،
به‌صورت نوتیفیکیشن دستگاه هم فرستاده می‌شوند. اعلان‌ها روی خود دستگاه ساخته می‌شوند (بدون سرور)،
پس برای رسیدنشان لازم است برنامه هر روز حداقل یک‌بار باز شود. در آیفون، اعلان فقط برای برنامه‌ی
نصب‌شده (Add to Home Screen) کار می‌کند.

## 📲 نصب

| دستگاه | روش |
|---|---|
| اندروید | کروم ← منوی سه‌نقطه ← «نصب برنامه» / «افزودن به صفحه اصلی» |
| آیفون و آیپد | سافاری ← دکمه‌ی اشتراک‌گذاری ⬆️ ← «Add to Home Screen» |
| ویندوز | کروم یا اِج ← آیکن نصب ⊕ در نوار آدرس ← «Install» |

برای نصب، برنامه باید روی یک آدرس **HTTPS** میزبانی شود (یا `localhost` برای آزمایش).

## 🚀 راه‌اندازی

### اجرای محلی
```bash
python3 -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

### انتشار روی GitHub Pages
در تنظیمات مخزن → **Settings → Pages → Source: GitHub Actions**.
با هر push روی شاخه‌ی `main`، ورک‌فلوی `.github/workflows/pages.yml` برنامه را منتشر می‌کند.

### میزبانی‌های دیگر
کل پروژه فایل ایستا است؛ پوشه را روی هر میزبان ایستا (Netlify، Vercel، لیارا، هر وب‌سرور) بگذارید.

---

## 💾 اطلاعات و پشتیبان‌گیری

اطلاعات در `localStorage` همان مرورگر/دستگاه ذخیره می‌شود؛ نه سرور دارد و نه بین دستگاه‌ها همگام می‌شود.
پس **مدیر و کارگر هرکدام روی دستگاه خودشان داده‌ی جداگانه دارند**.
از منو ← «پشتیبان‌گیری و بازیابی» می‌توانید فایل `json` بگیرید و روی دستگاه دیگر بازیابی کنید.

> رمز ۴ رقمی فقط جلوی دسترسی ساده را می‌گیرد و رمزنگاری واقعی نیست؛ جای قفل گوشی را نمی‌گیرد.

## 🗂 ساختار پروژه

```
index.html               پوسته‌ی برنامه (ورود، سربرگ، سه تب)
manifest.webmanifest     مشخصات نصب PWA
sw.js                    سرویس‌ورکر: کار آفلاین + کلیک روی اعلان
css/app.css              ظاهر برنامه (راست‌چین، دکمه‌های بزرگ)
js/jalali.js             تبدیل و قالب‌بندی تاریخ شمسی و اعداد فارسی
js/store.js              ذخیره‌سازی، دوره‌ها، نقش کاربر، پشتیبان‌گیری
js/calc.js               محاسبات: نرخ تبدیل، تلفات، هزینه، سود
js/notify.js             یادآورها و اعلان‌ها
js/ui.js                 ابزارهای رابط کاربری: پنجره، تاریخ‌گزین، پیام
js/views.js              سه تب اصلی
js/dialogs.js            پنجره‌های ثبت اطلاعات
js/app.js                راه‌اندازی، ورود، منو، تنظیمات
tools/make_icons.py      ساخت آیکن مرغ (Pillow)
```

بدون هیچ وابستگی، فریم‌ورک یا مرحله‌ی build — فقط HTML/CSS/JS ساده.
